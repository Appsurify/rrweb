    ℹ️ About Visual Coverage

    This is a demo application showcasing the integration of Visual Coverage with Cypress.

    What is Visual Coverage?

    Visual Coverage is a tool that records visual sessions of your UI tests, allowing you to replay and analyze user interactions, DOM changes, and test execution flow.

    Features:

    • ✅ Automatic session recording
    • ✅ DOM mutation tracking
    • ✅ User interaction capture
    • ✅ Test coverage visualization
    • ✅ Easy integration with Cypress
